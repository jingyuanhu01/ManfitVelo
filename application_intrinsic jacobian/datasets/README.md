# Data used by the two application notebooks

Only analysis-ready derived arrays are included here. The FUCCI raw loom and
FACS exports are deliberately excluded from Git history. `SHA256SUMS` records
the exact files used to execute the notebooks.

## FUCCI cell-cycle dataset

Source: Mahdessian et al., *Spatiotemporal dissection of the cell cycle with
single-cell proteogenomics*, Nature (2021),
[doi:10.1038/s41586-021-03232-9](https://doi.org/10.1038/s41586-021-03232-9),
with upstream materials from
[CellProfiling/SingleCellProteogenomics](https://github.com/CellProfiling/SingleCellProteogenomics).

The included arrays were generated by `../prepare_fucci_data.py` from the
upstream velocyto loom and three FACS index-sort exports:

- `X_fucci.npy`: 1,067 × 30 RNA-state PCA coordinates.
- `V_fucci.npy`: matching RNA-velocity PCA coordinates.
- `expr_hvg_fucci.npy`: log-normalized expression for 2,000 HVGs.
- `genes_fucci.txt`: the HVGs corresponding to the expression matrix.
- `phase_category_fucci.npy`: independently measured FACS categories.
- `phase_fucci.npy`: continuous circular ordering constructed from the two
  FUCCI fluorescence channels; it is not the paper's published pseudotime.
- `checkpoint_boundaries_fucci.json`: descriptive category-transition
  locations along that constructed ordering.

To rebuild these arrays, obtain the raw files from the upstream project and
either place its `RNAData` directory at
`datasets/fucci_cellcycle/raw/extracted/input/RNAData` or set
`MANFITVELO_FUCCI_RAW_DIR` to that directory before running:

```bash
python prepare_fucci_data.py
```

## Curated 33-gene cell-cycle dataset

This comparison dataset contains 2,793 cells, a 33-gene state/velocity panel,
a two-dimensional FlowMap embedding, and an independently measured,
protein-derived continuous cell-cycle state (`color_cell_cycle_relativePos.npy`).
It has no supplied categorical phase boundaries. The project-level provenance
of the continuous protein measurement has been confirmed, but the exact assay,
protein channel, upstream accession, and primary citation should be added when
that metadata is available.

Accordingly, the second notebook uses this state only for descriptive external
ordering and does not claim phase-wise significance or independently validated
DEGs.
